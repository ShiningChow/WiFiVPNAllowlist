# VPN 白名单守卫

一款本地运行的 macOS 菜单栏 App。规则是“默认拒绝”：只有当前默认网络使用 Wi‑Fi、能读到 SSID，并且该 SSID 精确命中白名单时，才允许 VPN 继续连接。

## 已实现

- 菜单栏实时显示 `ALLOW / BLOCK / PAUSED`。
- 配有专属的 Wi-Fi 盾牌 App 图标。
- 按自然月和 Wi-Fi 名称分别统计总流量、下载量和上传量，可回看有记录的历史月份。
- 每个 Wi-Fi 的月度流量进一步区分“梯子开启时”和“未开启时”；升级前的数据保留为“未分类”。
- 白名单本地保存，不联网、不上传。
- SSID 大小写敏感、精确匹配。
- 定位权限被拒绝、SSID 不可读、没有网络、默认网络走网线或网络正在切换时，默认阻止 VPN。
- 每 2 秒检查一次，网络变化和睡眠唤醒时会立即复查。
- 自动断开 `scutil --nc` 可见的系统 VPN。
- 非白名单网络中退出受控的第三方 VPN App；首次运行会自动纳入本机已经安装的 ClashX Pro。
- 如果受控 VPN App 在阻止状态下重新启动，会立即再次退出。
- 可从“应用程序”文件夹选择并添加其他 VPN App。
- 优先使用 macOS `SMAppService` 注册“登录时自动启动”；本机签名不支持时自动回退到用户级 LaunchAgent。

## 直接使用

构建产物位于：

```text
dist/VPN白名单守卫-macOS.zip
```

运行 `./Scripts/install-app.sh` 会把 App 安装到 `/Applications/VPN 白名单守卫.app`、注册登录时自动启动并立即打开。

首次启动：

1. 同意“定位”权限。macOS 把读取当前 Wi‑Fi 名称归入定位隐私权限；本 App 不请求实际坐标，也不会上传数据。
2. 点击菜单栏中的盾牌图标。
3. 在你允许使用 VPN 的网络上，点击“把当前 Wi‑Fi 加入白名单”；也可以手动输入家庭 Wi‑Fi、手机热点等名称。
4. 不要把学校 Wi‑Fi 加入白名单。
5. 开启“登录时自动启动”。如果显示“等待系统批准”，点击“打开设置”并在系统的登录项设置中批准。

流量统计从安装 1.1.0 或更高版本并运行后开始。点击菜单栏盾牌，在“Wi‑Fi 月度流量”中选择月份，就能查看 `Home WiFi` 等每个网络的总计、下载、上传，以及“梯子开启时 / 未开启时”的流量。数据保存在本机 `~/Library/Application Support/com.qiming.wifivpnallowlist/TrafficLedger.json`。切换 Wi-Fi、月份、网卡或梯子状态时会先重建采样基线，避免把两个网络或两种状态之间的流量串记。1.2.0 以前已经累计的流量无法可靠倒推当时状态，因此显示为“升级前未分类”。

白名单为空时，所有网络都禁止 VPN。进入允许网络后，本 App只解除阻止，不会替你自动启动或重连 VPN。

## 构建与测试

```bash
./Scripts/run-tests.sh
./Scripts/build-app.sh
./Scripts/install-app.sh
```

项目使用 Swift Package Manager 和系统框架，没有第三方依赖。最低支持 macOS 14。
完整 XCTest 套件需要 Xcode；如果机器只有 Command Line Tools，测试脚本会改为执行正式 App 编译和内置流量累计自检。

## 覆盖范围

当前版本明确覆盖：

- macOS 系统 VPN，以及能被 `/usr/sbin/scutil --nc list` 枚举的 VPN 服务。
- 本机的 ClashX Pro。
- 用户通过界面添加的其他 VPN/代理 App（通过退出 App 阻止）。

它不会修改学校网络、VPN 服务器或你的网络密码，也不会在白名单网络中自动打开 VPN。

## 重要限制

这是个人合规助手，不是不可绕过的学校级管控：

- 普通 macOS App 没有公开接口可以枚举并关闭所有其他厂商的 VPN。未知 VPN 客户端需要在“受控 VPN App”中添加，部分特殊客户端还可能需要单独适配。
- 检测与断开存在最多约 2 秒的反应窗口；退出本 App 或关闭登录项会停止守卫。
- SSID 名称可以被同名热点伪造，因此它适合避免误开 VPN，不适合作为高安全身份认证。
- 仅出现 `utun` 接口不代表 VPN；macOS 自身服务也会创建它们，所以本 App 不会粗暴删除 `utun`。
- 流量来自物理 Wi‑Fi 网卡的 64 位上下行字节计数，包含互联网、局域网以及 VPN 隧道承载的数据；App 未运行期间不会追溯估算，因此它适合查看趋势，但不等同于运营商计费账单。
- “梯子开启时”依据采样时是否存在活动系统 VPN、已启用系统代理，或受控 VPN App 正在运行来判断；这是状态分段统计，不是逐数据包解析。分流规则、局域网直连以及仅在浏览器内部配置的代理可能使它与 VPN 服务商自己的统计不同。
- 当前构建为本机 ad-hoc 签名，适合本机使用。向其他用户正式分发需要 Developer ID 签名和公证。

如果目标是学校统一、不可绕过地执行规则，应使用 MDM、标准用户权限、系统扩展/App 白名单和校园网网关策略，而不是只依赖个人菜单栏 App。
